# Probability-Collapse-Fock-States
This repository is a conversation I had with Grok and Gemini on probability collapsing N=20 Fock states and factoring higher-dimensional polynomials in polynomial time using split Euclidian Hamiltonians.

The method is using topological encoding of the AdS/CFT gravity bulk through higher dimensions (6D+) to probability collapse N=20 Fock states and factor higher-dimensional polynomial chains in 4D and below.

Grok got the probability collapse, but made a symmetry-error when  factoring a higher-dimensional polynomial chain, due to there not being a set to the polynomial chain. I got Gemini to factor a polynomial chain using the method in polynomial time.
